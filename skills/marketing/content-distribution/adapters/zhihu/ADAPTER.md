# 知乎 Adapter

## 状态

**导出待粘贴** — 知乎无公开写文章 API。

## 流程

1. 将官网文章内容适配为知乎编辑器友好的 HTML
2. 写入 `/tmp/dist/zhihu-<slug>.html`
3. 输出提示：请手动复制到知乎

## 内容适配

- 知乎编辑器支持富文本粘贴，HTML 是最佳格式
- 去掉掘金口语化风格，保持专业但通俗
- 文末加原文链接
- 图片需要单独处理（知乎不支持外链图片，需手动上传）

## 输出文件

```
/tmp/dist/zhihu-<slug>.html
```

文件内容：
```html
<h2>标题</h2>
<p>正文...</p>
...
<hr>
<p>原文链接：<a href="https://lanlnk.cn/insights/...">蓝联创新</a></p>
```

## 未来扩展

如果知乎开放 API 或有自动化方案，在此 adapter 中实现。
目前不投入自动化开发成本，手动粘贴 2 分钟即可完成。
